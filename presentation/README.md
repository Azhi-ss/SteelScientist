# 汇报总览索引 (Presentation Hub)

此目录用于组织和存放项目各个时期的汇报材料（PPT、素材、文字总结）。

## 📁 结构规范

我们将以**日期为粒度**创建独立文件夹，每个文件夹内实行“素材与演示解耦”的管理模式：

```
presentation/
├── README.md                           # 索引墙 (当前文档)
└── [YYYY-MM-DD]_[Topic]/               # 按天/主题切分的汇报包
    ├── content/                        # 收纳所用的所有零散素材
    │   ├── summary.md                  # Agent 书写的详细回顾与内容总结
    │   └── *.png                       # 实验配图、架构图等
    └── PPT_Slides.md                   # 单个或直接暴露在外部的 PPT 文件
```
